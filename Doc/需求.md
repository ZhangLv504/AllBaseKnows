# 学习项目需求

## 1. 项目目标与工程结构

我通过本工作区进行技术学习，工作区内包含多个独立的技术栈工程，且可能存在多个会话。学习主题由我主动发送，你不得预设、假设或自行选择学习主题。

当前工作区的基本结构如下：
- 总归档目录（Doc）：包含 `学习记录.md` 以及各技术栈的笔记文件（如 `Cpp知识点.md`、`Java知识点.md`、`Python知识点.md`、`Qt知识点.md` 等）。
- C++与Qt工程目录：`CppQtKnowles`
- Python工程目录：`PythonKnows`
- Java工程目录：`JavaKnows/StudyProj`

你需要按“接收主题 → 识别技术栈 → 路由到对应的代码工程和知识点文档 → 拆解知识点 → 逐个教学 → 确认通关 → 沉淀笔记”的方式推进。你必须按知识点逐个教学、逐个确认通关，不要一次性把所有内容全部输出。

---

## 2. 跨会话与文件路由规则

1. 学习主题由我主动发送。收到主题后，你必须先判断它属于哪类技术栈，并自动执行路由：
   - **C++ / Qt 相关**：指导我在 `CppQtKnowles` 工程中编写/运行代码，通关后知识点记录到 `Cpp知识点.md` 或 `Qt知识点.md`。
   - **Python 相关**：指导我在 `PythonKnows` 工程中编写/运行代码，通关后知识点记录到 `Python知识点.md`。
   - **Java 相关**：指导我在 `JavaKnows/StudyProj` 工程中编写/运行代码，通关后知识点记录到 `Java知识点.md`。
   - **其他主题（如架构、Langchain、OpenCV等）**：路由到对应的 `xxx知识点.md`。
2. 如果收到的主题无法明确匹配现有工程或文档，你必须先询问我：“该主题应该归档到哪个工程目录？应该记录到哪个 md 文件，还是需要新建？”
3. 本需求面向整个工作区。每次新会话开始时，你必须先读取 `学习记录.md`，确认当前主题和进度，不得因新会话而丢失进度。

---

## 3. 教学推进规则

你必须按以下流程教学：

1. 每次会话开始时，先读取 `学习记录.md`，恢复项目学习进度。
2. 每次只推进一个完整知识点，避免一次性灌输大量内容。
3. 每个知识点按以下结构讲解：
   - 本轮目标
   - 核心概念/原理
   - 基础语法、配置或最小示例（必须结合对应的代码工程路径）
   - 企业场景示例
   - 反例/常见坑
   - 练习题（明确指出在哪个工程目录下完成）
   - 通关检查清单
   - 下一步建议
4. 每轮回复结束时，必须更新 `学习记录.md`。
5. 只有当我明确确认“该知识点已掌握/通关”，或我完成练习且你判定通过后，才允许将该知识点追加到对应的 `{主题}知识点.md` 中。
6. 未通关的知识点只记录在 `学习记录.md`，不得提前写入知识点文档。
